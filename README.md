# 野草系统（YecaoST）

去中心化的本地餐饮 / 外卖网页系统。第一阶段以**单店**为主：**堂食优先、外卖为辅**；店铺自管菜品、订单、服务员 / 后厨 / 骑手工作台与支付配置。

仓库文件夹名：`YecaoST`。对外名称：**野草系统**。

## 这套系统能干什么（白话）

- 客人用手机浏览器点菜、下单、付款（现金 / 商户微信 / 演示支付等，按店配置）。  
- 店主在网页后台管菜品、桌台、员工、支付与订单。  
- 服务员 / 后厨 / 骑手在本店**工作台**处理现场订单。  
- **钱进店家自己的收款账户**；野草不代收、不抽佣。

另外，项目正在交付 **「野草本地营业内测版 V1」**：一家店在自己的 Windows 电脑上本地营业（托盘启动、店内 WiFi、安装包）。说明见 [`docs/V1本地营业内测版.md`](docs/V1本地营业内测版.md) 与 [`docs/V1本地营业用户说明书.md`](docs/V1本地营业用户说明书.md)。

## 快速开始（本机开发）

> 下面是给**开发者 / 部署者**改代码、本机调试用的。普通访客请直接打开上面的 **yichbo.com**。  
> 若你装的是 **V1 安装包**，请看 [`docs/V1本地营业用户说明书.md`](docs/V1本地营业用户说明书.md)，不要按本节 `runserver` 操作。

1. 安装 **Python 3.11**（或兼容版本）。  
2. 在项目目录创建并启用虚拟环境 `.venv`，安装依赖：见 `requirements.txt` 与 [`docs/环境与依赖清单.md`](docs/环境与依赖清单.md)。  
3. 启动（示例）：

```text
.\.venv\Scripts\python.exe manage.py runserver
```

同一 WiFi 下手机访问本机时可用：

```text
.\.venv\Scripts\python.exe manage.py runserver 0.0.0.0:8000
```

4. 本机浏览器打开：`http://127.0.0.1:8000/`（**仅本机调试**）。对外访问请用 **<https://yichbo.com/>**。
