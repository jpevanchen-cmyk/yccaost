## 1. 定位与原则

| 项 | 规则 |
|:---|:---|
| **目的** | 帮助首次访问者快速了解野草**开店**流程（卖家线）；不是正式 tutorial 账号体系 |
| **演示店** | 固定 **「野草官方小店」**（官方标记、不参与体验日清） |
| **大步脱钩** | **每一大步独立**：从主页选某大步、或上一步点「继续下一大步」时，均**整页重新打开**该大步入口，**不**在上一步停留的页面/状态上直接续播 |
| **进度** | **不存服务器**；第 **1～6** 大步细则见各章（已定）；第 **7～13** 大步**小步表与演示方式（只观摩 / 可写）待定**，由开发者逐步定稿 |
| **注册** | 第 1 大步**不真提交**开通表单 |
| **交互** | 与高亮框 + 说明文案 + 可选演示输入/演示点击；须真点的步骤标注 **【须点击】**；倒计时结束可自动执行（与第 3 大步同模式） |
| **毕业窗** | 每大步结束：**标题 + 小结 + 下一条名称**；可继续同线下一步或退出 |
| **买家线** | **尚未纳入 v2 定稿**；后续单独增补，**不在本文档** |

**代码模块（卖家线）**：`waimai/onboarding/tour_seller.py`（大步脚本）、`waimai/static/waimai/onboarding/experience.js`（前端引导）。

**说明框通用操作**（各小步一致）：

| 控件 | 作用 |
|:---|:---|
| **上一步** | 退回上一小步（第一步时不可点）；若上一小步在不同页面会自动跳转 |
| **下一步** | 进入下一小步；最后一步显示「本步完成」 |
| **不自动切换到下一步** | 勾选后隐藏倒计时，不再自动跳转，须手动点「下一步」 |
| **退出体验** | 结束引导并离开体验 |

勾选「不自动切换」在本浏览器标签内记住，刷新后仍生效。

## 19. 待施工 · 手机小屏引导布局（2026-07-28 定稿 · **未写代码**）

> **背景**：开发者用 **iPhone SE 3** 试跑 `/experience/` 卖家引导时，说明框（`.yc-exp-tour-card`）经常 **挡住高亮演示区**，看不清当前小步要点。  
> **本期决定**：**今天不改代码**，仅本文档 + **`2-开发进度.md`** 留档；日后单独口令施工。

### 开发者确认

| 项 | 决定 |
|:---|:---|
| **适用范围** | **只改手机**；电脑 / 宽屏 **保持现状** |
| **方案** | **A + C**（见下） |
| **说明框默认位置（手机）** | **屏幕底部**（接受） |
| **仍可拖动** | 保留现有拖动能力；底部布局下加一句「可拖动说明框」提示 |

### 方案 A · 手机专用「底部说明条」

| 项 | 规则 |
|:---|:---|
| **触发条件** | 窄屏 / 矮屏（建议：`innerWidth ≤ 480` **或** `innerHeight ≤ 700`；含 iPhone SE 一类） |
| **说明框** | **固定贴底**（类似底部抽屉）；`max-height` 约 **35%～40%** 视口；正文可滚动 |
| **高亮区** | 视口 **上方约 55%～60%** 专供演示；说明框 **不与高亮矩形重叠**（复用或扩展现有 `placeCardClearOfHighlight` 思路） |
| **滚动** | 小步切换时把 `[data-yc-tour]` 目标滚到 **上方区域**（勿再用 `scrollIntoView({ block: 'center' })` 占满中间） |
| **电脑** | 不命中上述条件 → **现有** `placeCard` 逻辑不变 |

### 方案 C · 说明更紧凑（仅手机）

| 项 | 规则 |
|:---|:---|
| **说明框高度** | CSS 媒体查询：手机 `max-height` 由约 **70vh** 降至约 **40vh**（与 A 一致） |
| **文案** | 优先 **短标题 + 一两句**；过长说明可 **折叠 /「展开全文」**（实施时定） |
| **字号** | 可略缩小正文与 tips，保证一屏内少滚动 |

### 主要改动面（日后施工参考）

| 模块 | 内容 |
|:---|:---|
| `waimai/static/waimai/onboarding/experience.js` | 小屏检测；`placeCard` / `scrollTourTarget` 分支；底部固定定位 |
| `waimai/static/waimai/onboarding/experience.css` | `@media` 手机：`.yc-exp-tour-card` 贴底、限高、圆角顶栏 |
| **验收** | **iPhone SE 3**（或同等窄屏）实机：任意卖家小步 **高亮区不被说明框挡住**；电脑回归 **与改前一致** |
