## 1. 这是什么

野草本地营业 V1：在**你们店里的一台 Windows 电脑**上安装野草，用店内 WiFi / 局域网营业。

- 那台电脑跑野草服务；右下角有**托盘小图标**。  
- 服务员手机、后厨平板、客人手机**只开浏览器**，不装服务端。  
- **不要求**公网固定 IP；桌码用店内能打开的地址即可。  
- 钱进**你们自己的**收款账户；野草不代收、不抽佣。

## 2. 平时怎么开、怎么关

### 2.1 开机营业

1. 双击桌面或开始菜单里的 **「启动野草」**（或安装目录同名项）。  
2. 右下角出现托盘图标。  
3. 右键托盘 → **「显示状态窗口」** 打开控制台。  
4. 在**装野草的那台电脑**上打开老板后台：优先用控制台的打开入口；若点不开，可在本机浏览器试 `http://127.0.0.1:端口/accounts/login/`（端口以向导为准，常见 8000）。  
5. 手机/平板须连**同一店内 WiFi**，用「堂食营业」里保存的局域网地址（或桌码），**不要**用 `127.0.0.1`。

### 2.2 关窗口 ≠ 退出

- 关掉状态窗口 = **最小化到托盘**，营业**不中断**。  
- 要完全停掉：在状态窗口点 **「退出野草」**（会先备份再停）。若设了退出密码，会先问密码。

### 2.3 可选：开机自启、启动/退出密码

安装时可勾选开机启动（默认一般不勾）。  
状态窗口的密码设置里，可要求「启动野草时要密码」「退出野草时要密码」。两项都不勾并保存 = 清掉这类密码。

## 3. 第一次安装（向导）

装完后第一次打开，网页会走 **首次向导**（店名、老板账号、端口/本机地址、插件、支付、备份目录等）。

- 向导里创建的**老板账号**，同时管本机这台「服务器」。  
- V1 **关闭对外注册**：别人不能在网上自助开店。  
- 向导完成后即可进店主后台、布置菜品与桌台。

更细的范围说明见 [`V1本地营业内测版.md`](V1本地营业内测版.md)。

## 4. 谁从哪进

| 角色 | 从哪进 | 能干什么（概要） |
|------|--------|------------------|
| **店主（老板）** | 浏览器打开本机营业地址 → 登录店主账号 | 管店、员工、支付、订单查询、堂食等 |
| **服务员 / 后厨 / 骑手** | **本店工作台**链接或二维码（带店铺码） | 现场接单、备餐、配送；**进不了**店主后台 |
| **客人** | 扫桌码 / 打开点菜页 | 点菜、下单、付款 |

重要：

- 工作台和店主后台是**两套门**，员工请用工作台，不要找「网站总登录」那套云端玩法。  
- **不要同一浏览器双开店主 + 员工**：容易互相踢下线、权限看起来乱。店主用一个浏览器（或普通窗口），员工用另一个或无痕窗口。  
- 公共电脑请勿勾选「记住密码」。

## 5. 店主第一次布置（简要）

1. 用老板账号登录 → 进**店铺管理**。  
2. **商品上架**：加菜、整理菜单。  
3. **堂食营业**：营业时段、桌台、桌码；需要时导出桌贴打印。  
4. **员工工作台**：建服务员 / 后厨 / 骑手账号，保存本店工作台二维码。  
5. **支付设置**：现金 / 商户微信 / 演示支付（演示仅便于试流程；真营业请按开通指南配置微信并关闭不该开的演示）。  
6. 员工手机扫工作台码上班。

真微信收款步骤见 [`卖家微信支付开通指南.md`](卖家微信支付开通指南.md)。

## 6. 客人怎么点（堂食要点）

1. 扫桌上的码（或打开店员给的点菜链接）。  
2. 选菜加入购物车后下单，按页面提示付款。  
3. **一桌一单**：同一桌可继续加点，合并在同一主单（常用）。  
4. **拼桌单**默认慎用：规则不同，开启前请在后台看清提示。

开台后会有**本单专属加点码**；翻台后作废。桌正在用时，陌生人乱扫物理桌码，应找服务员，不能随便并进别人的单。

## 7. 店铺工作台

入口：店主在「员工工作台」查看二维码与地址。

| 视角 | 常见操作 |
|------|----------|
| **服务员** | 看新单、上桌/交付、协助收款、堂食完成等 |
| **后厨** | 待备列表、按份备好 |
| **骑手** | 接配送、取餐、送达（若店开了外卖履约） |

员工可切换上班 / 休息 / 下班；可查看本人操作记录。店主在后台「操作留痕」看得更多。

**订单管理**页主要是**查历史**；现场接单请到工作台。

## 8. 备份与恢复（必读）

| 时机 | 做什么 |
|------|--------|
| 每天约 24:00 | 自动备份到安装目录下的 `backup`（若已按向导配置） |
| 正常「退出野草」 | 再备一份 |
| 随时 | 状态窗口 → **「立刻备份到所选文件夹」**（可选 U 盘） |

- 备份是保险，不是每按一下键都存一份。  
- 若启动时提示营业库损坏：按窗口说明，用最近可用备份恢复；**不要强行在坏库上继续营业**。  
- 建议给跑野草的那台电脑配不间断电源（UPS），减少突然断电风险。

## 9. 忘记密码

| 情况 | 怎么办 |
|------|--------|
| 记得旧密码 | 登录后到改密码页修改 |
| 老板登录密码忘了 / 托盘密码忘了 / 操作锁忘了 | 在**装野草的那台电脑**上运行 **「本机忘记密码重置」**（开始菜单或安装目录） |
| 重置时 | 按窗口提示填写确认词（如 `确认重置`）；须能操作到本机 |

重置会清相关本机保护口令并重置老板登录（以工具窗口说明为准）。**不能**靠网上远程替你重置。

## 11. 常见问题

**问：关掉状态窗口，生意是不是停了？**  
答：没有。只是藏到托盘。要停掉请点「退出野草」。

**问：换了 WiFi、手机热点或换了宽带/路由，电脑点托盘打不开、手机扫码也不行？**  
答：换网后电脑的局域网号通常会变。  
1）在**装野草的那台电脑**浏览器打开 `http://127.0.0.1:端口/accounts/login/`（端口常见 8000）进后台。  
2）到「堂食营业」把桌码局域网改成**当前**电脑局域网号并保存（四段数字可在本机查）。  
3）若桌上贴的码还是旧号，改完后须**重新导出打印**。  
（程序里「检测当前 IP / 一键更新」本机已做，见 [`V1本地营业内测版.md`](V1本地营业内测版.md) §2.1；**当前对外安装包可能尚未带上**。）

**问：员工用网站上的「登录」进不去？**  
答：员工请用本店**工作台**二维码/链接。

**问：卸载后数据还在吗？**  
答：卸载默认**不删**营业库和 `backup` 里的备份。要彻底清除须手动删安装目录剩余文件。

**问：想了解野草产品、看在线试跑？**  
答：打开 **<https://yichbo.com/>**。

**问：云服务器怎么部署、超级管理员怎么弄？**  
答：那是另一条线，见 [`服务器部署手册.md`](服务器部署手册.md) 与 [`用户使用说明书.md`](用户使用说明书.md)，不在本 V1 说明书范围。
