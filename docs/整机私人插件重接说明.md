# 整机私人插件 · 正式服务器重接说明（白话）

> **读者**：正式服务器部署者  
> **背景**：私人工具包改为「整机插件」形态；留言板由主程序自管。  
> **目标**：关掉旧硬挂认知，按插件方式重新接上；**不要求清空营业库**。  
> **以后**：统一「插件中心」管理壳见 **`docs/插件中心框架.md`**（§5.18 / A.15.21）；本文件是当前部署者操作单，不是普通人安装向导。

---

## 1. 主程序先更新

1. 按惯例拉取代码、安装依赖（若有）。  
2. 执行数据库升级：`python manage.py migrate`  
3. 留言板表由 **waimai** 迁移维护；无需再靠私人包建留言表。

## 2. 私人包怎么接

1. 仍把 `owner_toolkit` 目录放到服务器约定位置（或更新 zip 覆盖）。  
2. `.env` 保持（或设置）：
   - `YECAO_OWNER_TOOLKIT_ENABLED=1`
   - `YECAO_OWNER_TOOLKIT_PATH=...`（指向私人包目录）  
3. 再执行：`python manage.py migrate`（会跑私人包侧迁移；留言板相关已改为不抢建表）。  
4. 重启网站进程（Gunicorn 等）。

## 3. 验收

| 检查 | 期望 |
|------|------|
| 关闭 `YECAO_OWNER_TOOLKIT_ENABLED` 后重启 | 主程序（含留言板正式入口）仍可用 |
| 再打开私人插件 | 通知设置、访客统计等入口回来 |
| 新留言通知 | 仍走私人包通知设置（若已配置发信） |
| 旧「私人包留言 URL」 | 应能跳到主程序留言相关页 |

## 4. 不要做的事

- 不要为了接插件而删除 `db.sqlite3` / 业务库。  
- 不要把 `owner_toolkit` 打进 V1 本地营业安装包。

## 5. 主页文件下载与访客统计（2026-08-12 · 2026-08-13 补）

- **下载（可记账）**：用服务器主页「文件下载」积木上传文件；走 `/home-download/...` 记账，不要只宣传 `/media/` 直链。  
- **另渠道（可不记账）**：V1 安装包也可挂在 **GitHub 发行版（Releases）附件**；**禁止**把 exe 提交进代码树。官网主页与发行版可并存；README 已写双入口。  
- **访客**：真人须有点击；无点击另计；扫描分开。  
- 细则：完整版手册 **A.10.11**；操作见拥有者《私人工具包操作方法》。
