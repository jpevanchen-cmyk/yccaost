# 野草本地营业 · 版本迭代说明

> **读者**：店主、下载安装包的人、智能体  
> **用途**：记录每一个对外安装包版本「这一版是什么、比上一版多了什么」。  
> **产品线名称**：野草本地营业内测版 V1（方案里常称 V1.0）。  
> **安装包版本号**：与产品线名称分开。例如产品线仍叫 V1，安装包可以是 **1.0**、**1.01**、**1.02**……  
> **写法**：对外一律用 **1.01** 这种两段数字，不要和 **1.0.1** 混用。  
> **维护**：每次准备重新打包前，必须先改本文（旧版条目不删、不改写历史；新版加在「版本记录」最上面）。改完再改安装脚本里的版本号，再打包。  
> **最后更新**：2026-08-19（**1.01 已挂网**：官网主页 + GitHub `v1.01-local-beta`）

## 版本记录

### 1.01（2026-08-17 本机再打 · 2026-08-19 已挂网）

相对上一对外包 **1.0**，本版主要多了这些（给店里本机用的）：

- **安装包自带可带走的运行环境**（含托盘控制台要用的窗口零件）。朋友电脑**不必**再单独安装 Python；也不再拷贝开发机上那个会回头找原电脑路径的小环境。启动、准备数据库、忘记密码都只认安装目录里这份。  
  （中间曾短暂按 1.02 试打文件名，**未挂网**；对外仍叫 **1.01**。）

相对更早的本机 1.01 程序能力，还包括：

- **本机后台和店内扫码分开**：在装野草的那台电脑上打开老板后台，默认走这台电脑自己的地址；给手机扫的桌码、工作台码只认堂食里保存的那一份店内地址。控制台能看出「已保存的」和「当前探测的」是否一致，不一致时可一键更新（会提醒可能要重打桌贴）。  
- **控制台检测与堂食营业同一套**：点「检测当前 IP」会弹出已保存和当前探测；问不到会说明，不再只显示「检测完成」而下面仍是空的。  
- **控制台窗口可往下滚**：内容比窗口高时右侧有滚动条，底下「启动/退出密码」能看见。  
- **员工权限勾选更不容易漏项**：勾业务权限时，必须一起开的项会当场带上并锁住。  
- **待支付超时**：微信/演示等先付单，超过店里设定的时限（默认约 30 分钟）会自动取消，并说明超时分钟。取消前会先问微信、并请求关掉这条支付；取消之后一段时间还会再问，避免出现「单已经取消、钱却又付进来」。若取消后才到账：**不把单救活**，自动按原路退。  
- **换支付方式能真正换走**：点换之前先确认是否放弃当前微信码；确认后关掉这张码再选别的。同一张订单若短时间反复新开微信码，本单不能再申请微信，其它已开通方式仍可选。  
- **微信账单上的商品名带当前店铺名称**（例如：野草订单-某某小店 再加对外订单号）。已经开出去的旧码名称不会变，新开的码才带店名。  

**本版安装包文件名**：`野草本地营业_V1.01_安装包.exe`  
**本机位置**（未进代码仓库）：`installer\output\` 下同名文件。  
**挂网**：**已挂**官网主页下载入口，以及 GitHub 发行版 `v1.01-local-beta`（请只下 `.exe`）。开发者确认朋友按此安装成功。旧标签 `v1.0.0-local-beta` 是 **1.0**，不要再当当前包。

覆盖安装：一般会更新程序文件，店里已有的营业数据和备份尽量保留。覆盖前仍建议先备份。

### 1.0（第一个对外内测包 · 约 2026-08-13）

这是第一个拿出去给人下载的 Windows 安装包。

**这一版是什么**

- 给**一家店**在自己的 **Windows 电脑**上本地营业（内测）。  
- 双击安装包安装；右下角托盘开关服务；老板、员工、客人用**浏览器**办事，不另装一个大窗口客户端。  
- 服务员手机、后厨平板、客人手机连店里 WiFi，扫码或打开店内地址即可。  
- **不要求**公网固定地址；钱进店自己的收款账户，野草不代收。  
- 第一次打开走网页向导：店名、老板账号、端口、插件、支付、备份目录等。对外注册关闭，不能网上自助开店。  
- 每天零点以及正常退出时自动备份；控制台可立刻备份到所选文件夹。库损坏时启动可问是否用最近完好备份。  
- 本机忘记密码有专门入口（须在装野草的那台电脑上操作）。  
- 关调试后页面仍应有样式（安装时已收集页面文件）。  
- 当时已带上的本机能力还包括：托盘控制台、启动/退出可选密码、操作锁、微信收款与最小退款、打开订单页时查收/退款结果等（以当时程序为准）。

**当时怎么下**

- 官网主页下载入口  
- GitHub 发行版：`v1.0.0-local-beta`（请只下 `.exe`）

**当时安装包文件名**：`野草本地营业_V1_安装包.exe`  
**当时安装程序内部版本号**：`1.0.0`（对外就叫 **1.0**）

**这一版还没有、后来写进 1.01 的**（不要当成 1.0 已有）：本机后台与店内地址拆开、控制台与堂食共用测号、控制台可滚动、员工权限勾选锁定、待支付超时关通道与追问、换支付方式关码、微信账单带店名。
