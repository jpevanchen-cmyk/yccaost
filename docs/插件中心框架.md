# 插件中心框架（公开摘要 · 以后实现）

> **状态**：**2026-08-10 定案**（仅文档；**代码未做**）  
> **完整正本**：私有 `开发方案-完整版.md` **§5.18**、手册 **A.15.21**  
> **一句话**：野草提供「插件中心」管理壳；插件由用户放入指定目录；中心负责发现、校验声明、启用/停用；先支持本地包，商店以后再说。

---

## 1. 两类插件（须分轨）

| 类型 | 谁管 | 例子 |
|:---|:---|:---|
| **整机插件** | 服务器拥有者 / 部署者 | 可选的服务器扩展（如拥有者工具类能力） |
| **店铺业态插件** | 店主（按店开关） | 饮食、履约等 |

管理壳可以统一，加载语义不能混。

## 2. 目标怎么装（以后做界面）

1. 用户自己下载插件包。  
2. 放到野草项目**指定目录**（路径实现时写入说明书）。  
3. 插件中心扫描列表，校验插件自带的**声明**（名称、编号、兼容版本、权限说明等）。  
4. 在中心里**启用**后才真正挂进运行；可停用；卸载 = 先停用再可选删文件。  
5. **先本地包**；联网商店以后另定。

## 3. 底线

- 无合格声明 → 不加载。  
- 不装可选整机插件时，主程序仍须能完整运行。  
- V1 本地营业安装包默认不带私人整机插件。  
- 遵守开源许可与数据安全附录；插件不得绕过隐私硬规则。

## 4. 与现状

- 饮食/履约：已有店铺级开关，尚无统一「插件中心」壳。  
- 整机私人扩展：已可按目录 + 开关挂载；「中心内安装」属本框架以后实现。  
- 临时部署说明：`docs/整机私人插件重接说明.md`（部署者用，不是普通人安装向导）。
