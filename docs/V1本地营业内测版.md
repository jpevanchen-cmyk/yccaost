## 2. 店里怎么连

```
┌─────────────────────────────────────┐
│  Windows 主机（装野草的那台）         │
│  · 托盘小图标 + 后台服务              │
│  · 浏览器：老板后台 / 本机工作台      │
└──────────────┬──────────────────────┘
               │ 店内 WiFi / 局域网
     ┌─────────┼─────────┐
     ▼         ▼         ▼
  服务员手机  后厨平板   客人手机
  （浏览器） （浏览器） （扫桌码）
```

- **一台 Windows** = 野草服务器 + 店内入口（手册里的 ①+② 合体）。  
- **其它设备只装浏览器**，不装野草服务端。  
- **不要求** 宽带公网 IP；桌码用 **局域网固定地址或店内固定名字**。

### 2.1 本机打开后台 ≠ 店内可扫地址（2026-08-14 定案 · 本机代码 ☑）

> **完整正本**：E 盘方案 **§5.16.3.1**、手册 **A.15.19**。

| 项 | 定案 |
|:---|:---|
| **真源** | 店内可扫网址 **只认堂食那一份**；不再另存一份「V1 站点局域网」当真源 |
| **本机开后台** | 托盘控制台 **「本机打开后台」** 默认 `http://127.0.0.1:端口/…`（装野草的那台电脑自己开）；**不**绑死向导里填过的局域网 |
| **店内入口** | 手机/平板/桌码/工作台码 → 只用已存局域网或店内固定名字；**禁止** 127 |
| **向导写入** | 探测/填写的局域网写入堂食桌码地址（并放行） |
| **探测与一键** | 控制台常显：已保存 / 当前探测 / 是否一致；「检测当前 IP」+ 不一致时可一键更新（只写堂食 + 放行名单）；更新后提醒可能重打桌贴 |
| **堂食页** | 与托盘同一套对比/一键逻辑 |
| **禁止** | 静默改已存 IP；桌码用 127；只改打开方式不更新堂食与放行 |

**本机代码已做（2026-08-14）**。当前对外安装包可能尚未带上；换网后若仍是旧包，请先用本机 `127.0.0.1:端口` 进后台，再到堂食改局域网。

### 2.2 和完整第一阶段谁先谁后（2026-08-14 仅文档）

> **完整正本**：E 盘方案 **§5.19**、手册 **A.1 落地顺序**。  
> **白话**：「拆成 1+2」= **同一台电脑开两道门**（客人一门、维护一门），**不是**两台电脑。

| 步 | 做什么 |
|:---|:---|

| **C** | 以后要宣称正式营业形态：先拆**同机两道门** |
| **D** | 云上门面（③）可选；不挡店里本地营业 |
| **E** | 完整第一阶段发布时，仍是一台电脑（那时可以已经有两道门） |

## 4. 安装与备份

| 项 | 规则 |
|:---|:---|
| **安装位置** | 推荐 **非系统盘** |
| **备份目录** | 默认 **`安装目录\backup`**（安装向导可改；自动备份写这里） |
| **自动备份** | 每天 **24:00** + **正常退出野草** 时再备一次 |
| **立刻备份** | 托盘菜单 **「立刻备份到所选文件夹…」** → 选文件夹 → 生成一份副本（可拷 U 盘） |
| **关窗口** | **最小化到托盘**（不是退出） |
| **完全退出** | 托盘菜单 **「退出野草」** → 备份 → 停服务 |
| **目录权限** | 安装时收紧，减少别的用户随便进安装目录 |
| **BitLocker** | **不是野草功能**；要求更高者可自行加密整盘（见说明书） |

## 8. 数据安全（断电、防乱改）

### 8.1 尽量不丢已保存的账

- 重要操作 **整笔成功或整笔不算**；建议 SQLite **WAL 模式**。  
- **备份** 是保险副本，不是每次按键都备。  
- 启动时 **检查数据库是否完好**；坏了提示用最近备份恢复。  
- **UPS** 指的是 **跑野草的那台 Windows 营业电脑**，不是外接收银机。

### 8.2 防营业数据被乱改（V1.0 方向）

- 关对外注册、隐藏无关入口、生产模式关调试。  
- 登录权限、员工分工、操作审计、游客桌台归属（已有基础，V1 须补全清单）。  
- 登录 **连续试密码** 须暂锁并记日志（**第 8 项 ☑ 本机**）。  
- 商户微信 **收款+退款轮询** 须验收（**第 10 项**；退款代码 **第 9 项**）。

### 8.3 V1.1（V1.0 成功后再做）

- **主密码 + 数据库加密**（可与启动密码 **同一套口令**，机制不同）。

## 9. 可选安全功能（可不设；设了也能关）

| 功能 | 锁什么 | 不锁什么 |
|:---|:---|:---|
| **启动/退出密码** | 启动野草、完全退出 | 最小化到托盘 |
| **操作锁** | **店主后台**、**服务器设置** | **工作台全部 Tab（含收银台）**、服务员/后厨/骑手、客人点餐；**全店不停业** |

- 可 **5 分钟无操作自动锁** 或 **手动立即锁**。  
- 关闭或改密码须 **验证旧密码**。

## 10. 堂食桌台（饮食插件 · 全野草必做）

> V1 **必须带上饮食插件**；下列规则 **属于整个野草饮食能力**，不是 V1 独有。

| 规则 | 说明 |
|:---|:---|
| 桌态 | **空闲 / 启用中**（卖家后台）；服务员看板格显示 **空闲 / 启用** |
| 禁止双开 | 同一桌不能开两次 |
| 物理桌码 | 长期贴桌；仅 **空闲时首次开台** |
| 专属加点码 | 开台后生 **本单一次性** 码；翻台作废 |
| 分享 | 开台手机可分享给同桌 |
| 服务员 | 看板详情可出示 QR；**代客开台并点菜**、**帮此桌点餐** |
| 陌生人扫物理码 | 桌使用中且 **未绑本桌会话** → 找服务员，不能并进别人单 |
| 物理码 · 说明 | **同浏览器**已绑本桌时可重扫物理码（见 E 盘 **§5.16.10**） |
| 看板 UI | 固定格子总览 → 点桌详情；翻台静默刷新 |

**代码**：☑ 本机（2026-08-08 · 专属加点码 + 服务员看板 A/B/UI）。

## 11. V1 默认隐藏（代码保留）

体验开店、留言板、招聘、公网/③、服务器主页、店铺主页等 —— **默认不可见**（**仅 V1 模式为真时**；见下 §11.1）。

**保留**：店主后台、饮食/履约插件、店铺工作台。

### 11.1 开发机与手工部署（默认不是 V1）

| 项 | 说明 |
|:---|:---|
| **你的开发机** | 默认 **完整野草**；`runserver`、注册、开店等 **照常用** |
| **什么时候才是 V1** | 只有 **V1 安装向导装出来的店**，或你 **主动** 打开 V1 模式做测试 |
| **拉代码 / migrate** | **不会** 自动把开发机变成 V1 |
| **想在本机试 V1 界面** | 可 **临时** 打开 V1 模式；测完 **关掉** 继续全功能开发 |

细则见 E 盘开发方案 **§5.16.5.1**。
